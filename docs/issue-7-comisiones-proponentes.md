# Issue #7 - Gestión de Comisiones y Proponentes

## Objetivo

Implementar la base Java para la gestión de comisiones y proponentes dentro del sistema AIR.

## Archivos implementados

- `src/main/java/models/Comision.java`
- `src/main/java/controllers/ComisionController.java`

## Funcionalidad

El módulo permite representar comisiones y preparar la lógica de backend para registrar, listar y buscar comisiones.

## Validaciones iniciales

- No se permite registrar una comisión nula.
- El nombre de la comisión es obligatorio.
- Se permite listar comisiones registradas.
- Se permite buscar comisiones por nombre.

## Stack

- Java
- MVC
- Maven
- Tomcat
- Compatible con Azure SQL Server / T-SQL
